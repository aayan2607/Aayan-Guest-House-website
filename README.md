# Aayan Guest House Website

Website for Aayan Guest House, Kidderpore, Kolkata. Guests can see the rooms, prices and contact details, and send an enquiry.

**Live site:** (https://aayan2607.github.io/Aayan-Guest-House-website/)

## Features
- Room types with photos, amenities and prices
- Contact details, address and map
- Mobile-friendly layout

## Tech
Plain HTML, CSS and JavaScript in a single `index.html`, with photos in `images/`.

## How to run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.
